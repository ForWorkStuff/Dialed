Third-party software and models in Dialed
=========================================

The DJ's natural voice (folder tts/)
- Kokoro-82M speech model by hexgrad, Apache License 2.0. Not included in this folder: your browser
  downloads it on first use from https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
- kokoro-js 1.2.1, Apache License 2.0.
- Transformers.js 3.8.1 by Hugging Face, Apache License 2.0 (bundled inside tts/kokoro.web.js).
- phonemizer 1.2.1, Apache License 2.0 (bundled inside tts/kokoro.web.js). It embeds eSpeak NG compiled to
  WebAssembly, which is licensed under the GNU General Public License v3 or later.
  eSpeak NG source code: https://github.com/espeak-ng/espeak-ng
- ONNX Runtime Web 1.22 by Microsoft, MIT License (tts/ort/ and bundled inside tts/kokoro.web.js).
License files that ship with kokoro-js, Transformers.js and phonemizer are in tts/licenses/.
ONNX Runtime Web is MIT licensed: https://github.com/microsoft/onnxruntime/blob/main/LICENSE
